Part 3 · Chapter 16

Fit Settings: Resolution, Swarm Size, and Seeds

In This Chapter

  • Setting the population before the iterations
  • Choosing Δθ by a scan of χ²
  • Checking the fringe contrast
  • Running the fit several times, and reporting the spread

The fit settings decide how hard X-Ray Calc searches and what it compares. Three of them need a decision for every curve: the size of the swarm, the resolution Δθ, and the number of runs. This chapter makes those decisions for the Co/C multilayer CoC4, with the limits of Chapter 15: The near-bound rule. The other settings keep the values of Table 16-1.

The settings, and the ones you change

The settings are at the top right of the working area, as Chapter 14: Figure 14-3 shows. X-Ray Calc starts with 100 Iterations and a Population of 100. That swarm is too small for a multilayer.

Warning: settings that come with a project

A project file keeps the settings it was saved with. If you load your curve into someone else’s project, the fit uses their Δθ, their weighting and their swarm. It gives no message. The expert’s own CoC4 project, for example, opens with a Population of 500, 100 Iterations and TW χ² set to sqr. Check every field of Table 16-1 before the first fit (Chapter 8: The resolution).

Population before iterations

The Population is the number of particles in the swarm. The Iterations are the number of steps they take. The fitting procedure puts it this way: a larger population is what finds the right minimum, and more iterations of a small swarm do not. The X-Ray Calc 3 paper found the same (Chapter 9: When the fit stops). So set the population first.

One laboratory tested this on curves calculated from a known structure. With 500 and 2000 particles the thicknesses came out 0.13 Å wrong. With 5000 or more the errors were 0.03–0.07 Å. At 500 the contamination layer was undetermined. 50 iterations were worse than 100. 200 were no better than 100. The author’s own projects used a population of 5000 in every multilayer fit of 2026. A single film uses 2000 (Chapter 21: The single-film exceptions).

CoC4 has the two σ valleys of Chapter 9: Figure 9-2. In the lower one, C has σ = 2.53 Å and Co has 4.22 Å. In the other, the two values swap: C has about 4.3 Å and Co 2.6 Å. With 500 particles, two runs of five ended in the higher valley. With 2000, one run did. Their σ values then spread by almost 1 Å. With 5000 particles every run found the lower valley.

A small swarm run ten times longer also found it. But 500 × 2000 took 7.6 s, more than twice as long as 5000 × 200, for the same number of scored structures. Ten times the iterations made the run 7.7 times longer. Ten times the swarm made it only 3.5 times longer, because the graphics card scores the whole swarm at once.

Remember

Set the population first: 5000 for a multilayer. Then set the iterations. 200 is safe. On CoC4, 100 gave the same result in half the time.

Choosing Δθ by a scan

Δθ is the width of the blur that X-Ray Calc applies to the calculated curve (Chapter 8: The resolution). The fit never changes it. It depends on the instrument and on the measurement, so you choose it for each curve. The fitting procedure chooses it by a scan:

  1. Fit the curve at a start value of Δθ until the fit has converged.
  2. Type the next value of your window in Δθ, choose Calc > Auto Fitting (F7) and click Run. Note χ².
  3. Repeat for every value of the window, in steps of 0.001°.
  4. Keep the Δθ with the lowest χ².
  5. Run the full set of runs once at that Δθ (Several runs, and their spread).

One run at each Δθ is enough for the scan, because the scan compares the resolutions. The set of runs comes after it. Each point is a new fit. A recalculation of one fitted structure at another Δθ is not a scan, because that structure was fitted at the old Δθ. χ² values can be compared only over the same range and with the same weights.

The window belongs to your instrument. One laboratory’s window is 0.012–0.015°. The author’s own projects used values from 0.009 to 0.026°, set for each measurement.

Figure 16-1 shows the scan for CoC4. In the window, one run at each Δθ gave χ² = 1.2779, 1.2479, 1.2334 and 1.2337. The lowest is at 0.014°, so the rule picks 0.014°. Outside the window χ² falls a little further, to 1.2320 at 0.016°. Then it rises.

The figure shows more than the minimum. At 0.012 and 0.013° all five runs ended in the same valley, with χ² within 0.0008 of each other. At 0.014° two of the five runs ended in the swapped valley. At 0.015° three did. From 0.016° on, the single run ended there too. So the choice of Δθ decides which layer the fit gives the larger σ. At 0.014° and above, this curve doesn’t settle it.

Remember

The chosen Δθ is a setting of this fit. It is not a measurement of the beam divergence, and it doesn’t carry over to another curve. In tests on calculated curves, the χ² minimum lay above the true value: at 0.015° and 0.014°, for a true 0.013°.

The fringe contrast as a check

The fringes between the first two Bragg orders show the blur most clearly. Their contrast is each fringe maximum divided by the minimum next to it, averaged over the fringes. If the model’s fringes are deeper than the measured ones, Δθ is too small. Report the comparison beside the scan, and let the scan decide.

In X-Ray Calc, select the fitted model, calculate it with Calc > Run (F5) and choose Result > Fit report …. Its group Fringes between orders 1 and 2 gives the mean contrast, measured and calculated (Chapter 18: The fringes). You can also zoom in on the band and read a few pairs with the cursor, in the X and Y boxes of the Chart Info bar (Chapter 11: The Chart Info bar).

For CoC4 the measured mean contrast is 2.17. The model gives 1.94 at Δθ = 0.009°, 1.72 at 0.012° and 1.60 at 0.014°. At every Δθ of the scan the model’s fringes are shallower than the measured ones, so the check never asks for a larger Δθ. The scan still picks 0.014°, because χ² is summed over the whole fitting range and the fringes are one feature in it. On CoC4 the check and the scan point different ways, and you report both.

Several runs, and their spread

X-Ray Calc draws a new random seed for every Auto Fitting (Chapter 9: Random seeds). You can type a seed instead. The Advanced Settings button opens the Advanced fitting settings dialog. Its General group has a Seed box. Each fit records the seed it used, in the project and in the exported fit results. With the same seed, settings and starting model, a fit repeats exactly, but only on the same device. For the spread, leave Seed blank and run the fit five times at the chosen Δθ. One laboratory found that three runs understated the spread about 2.5 times. From five runs on, the spread stayed the same.

  1. Select the starting model in the project panel and choose Project > Duplicate Model. The copy becomes the active model.
  2. Choose Calc > Auto Fitting (F7) and click Run. The fit changes the copy. The starting model stays as it was.
  3. Choose Result > Export fit results… and save the result under the number of the run.
  4. Repeat from step 1 until you have five runs.

Every run starts from the same starting model. With SeedR ticked, a Periodic or Irregular run starts spread over the limits, so the runs are independent of each other. In Polynomial mode SeedR is grayed out, and the swarm starts around the model. A fit writes its result into the model. So a second Polynomial run on the same model would start around the first result. A fresh copy of the starting model avoids this. Run keeps the limits as they are. Calc > Resume Fitting would move them (Chapter 15: The density ceiling).

In X-Ray Calc

Result > Export fit results… writes one JSON file for the fit: χ², the scale, the time, the device and the seed, the fit settings and the fitted structure. Five files make the record of five runs.

What to report. Report the run with the lowest χ². Beside each of its parameters, give the sample standard deviation of that parameter over the runs. Use the standard deviation. The range grows with the number of runs, while the standard deviation stays about the same. Don’t average the runs. A mean over the runs is a structure that no run found.

Every run then gives C the larger σ (Chapter 17: Step 1, one period with the period free).

Warning: a small spread is not proof

Runs that agree show only that the fit keeps finding the same answer. They don’t show that the answer is right. In tests on a calculated W/B4C multilayer, the split of thickness between W and a WC interlayer came out wrong by up to 2 Å. The runs still agreed with each other.

What this means when you fit

Check every setting of Table 16-1 before the first fit, above all in a project you did not make.

Set the population before the iterations: 5000 × 200 for a multilayer.

Choose Δθ by a scan over your laboratory’s window, one run at each value. Keep the lowest χ², and report the fringe contrast beside it.

Run the fit five times at the chosen Δθ. Report the best run, with the standard deviation of each parameter beside it.

Then compare the modes (Chapter 17: Step 1, one period with the period free) and judge the fit (Chapter 18: Judging a Fit). Chapter 23: The report, item by item lists what to report: Δθ with its scan, the settings and the runs.
